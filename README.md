Survival on Island

My first 2D game! You're stranded on an island after a shipwreck.
Collect wood and stone, craft a tool, build a raft and sail away.

Made with Python, Pygame and Tiled. I drew all the pixel art myself in Piskel.

How to run

    pip install -r requirements.txt
    python main.py

Controls

- WASD — move
- E — collect wood / stone
- C — craft a tool
- F — build a raft at the sign
- Space — get on the raft
- Esc — quit
